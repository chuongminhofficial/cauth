# Support

| Topic | Route |
| --- | --- |
| Product/user support | `admin@cauth.io`, subject `cAuth Support` |
| Security incident | `admin@cauth.io`, subject `cAuth Security` |
| Host / country partnership | `admin@cauth.io`, subject `cAuth Partnership` |
| Copyright complaint | Product complaint workflow with reference ID |

Never send secrets or live credentials through these channels.
