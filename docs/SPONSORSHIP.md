# Sponsorship & Partnership Program

## Funding goals

Support may fund compute, storage, bandwidth, timestamping/verification, monitoring, security review, documentation, regional deployment and maintenance.

Sponsorship does not grant user-data access, privileged production credentials or security-control bypasses.

## Support categories

- Infrastructure Sponsor
- Security & Assurance Sponsor
- Regional Host Sponsor
- Strategic Technology Partner

Any benefits are agreed per engagement and are not guarantees of legal, financial or technical outcomes.

## Visibility

Sponsors may be acknowledged by name/logo with permission. Sponsorship alone does not imply private source access.

## Transparency

Record sponsor, category, period, intended use and material deliverables internally. Public claims should use only verified information.

## GitHub

GitHub Sponsors is built around support for open-source contributors. For a closed-source core, use the public project site or an eligible public sponsor profile for discovery and keep private source access separately controlled.
