# Host Security Baseline

Before activation, the operator should demonstrate:

- HTTPS and certificate renewal.
- OS/package patching.
- Strong administrator authentication and MFA where supported.
- Restricted network exposure.
- Secret storage outside Git.
- Restricted database access.
- Backup and tested recovery procedure.
- Monitoring and incident response contact.
- Appropriate audit-log retention.
- Secure SSO/SMTP/R2/Telegram/Cloudflare credential handling.
- Controlled application release process.

Higher-risk deployments should consider independent penetration testing and formal key-management controls.
