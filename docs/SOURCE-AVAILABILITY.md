# Source Availability

The cAuth Copyright Registry production implementation is proprietary.

This public repository publishes the project boundary rather than implementation source: architecture, security posture, release process, regional host requirements, partnership information and other non-sensitive material.

The private implementation repository is separate and access-controlled.

## Clean-history rule

Removing source files from an existing Git repository does not remove the source from its previous commits. The public repository must therefore start from a clean Git history.
