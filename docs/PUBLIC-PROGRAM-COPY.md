# Public Program Copy

## Regional hosts

cAuth is opening a regional host program for operators who want to run approved infrastructure in their country. Hosts manage their own infrastructure and local operations while application-level access, release policy and country-directory status are governed through the cAuth Admin Control Plane.

Applications should include organization, country, technical environment, domain, monitoring/backup plan, public contact and required integration metadata. Credentials and secrets are exchanged only through a secure handoff.

Approved partners may be listed as country representatives after review and agreement. The listing does not imply government affiliation.

## Sponsors

cAuth welcomes financial and in-kind support for infrastructure, security review, verification tooling, documentation and regional deployments. Sponsor benefits and acknowledgements are handled by agreement; sponsorship does not purchase privileged access or bypass security controls.
