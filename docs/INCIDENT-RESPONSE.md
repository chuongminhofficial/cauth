# Incident Response

## Severity

**SEV-1** — evidence integrity, auth bypass, exposed production secrets, or broad unauthorized access.

**SEV-2** — major service degradation, access-control defect, or contained host compromise.

**SEV-3** — localized bug or non-critical operational fault.

## First actions

- Preserve logs and request IDs.
- Revoke/rotate affected credentials.
- Isolate affected host/route where needed.
- Preserve original evidence-chain history.
- Record timeline and corrective action.

Public communications should distinguish confirmed facts from investigation status.
