# Quy trình phát hành

1. Chuẩn bị thay đổi có phạm vi rõ ràng.
2. Chạy PHP và Node checks.
3. Build CSS khi source CSS thay đổi.
4. Review tác động đến authentication, authorization, schema, storage và secret handling.
5. Tạo release notes và known limitations.
6. Tag release.
7. Deploy staging có kiểm soát trước production.
8. Ghi lại rollback/deployment reference.
