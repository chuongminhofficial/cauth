# Tình trạng cung cấp mã nguồn

Implementation production của cAuth Copyright Registry là proprietary.

Repository public này công bố ranh giới dự án thay vì source implementation: kiến trúc, posture bảo mật, release process, yêu cầu regional host, thông tin partnership và các tài liệu không nhạy cảm khác.

Private implementation repository được tách riêng và kiểm soát truy cập.

## Quy tắc Git history sạch

Xóa file source khỏi một commit mới không xóa source khỏi các commit cũ. Vì vậy repository public phải bắt đầu từ Git history sạch.
