# Đóng góp

Đây là dự án có **core mã nguồn đóng**. Thay đổi code chỉ được chấp nhận từ collaborator đã được ủy quyền.

1. Giữ thay đổi nhỏ, rõ phạm vi và dễ review.
2. Không commit secret hoặc dữ liệu deployment/khách hàng riêng tư.
3. Khi hành vi thay đổi, cập nhật check và tài liệu liên quan.
4. Mô tả tác động về security, schema, migration và rollback.

Onboarding regional host được xử lý qua chương trình host, không cấp source access thông qua pull request thông thường.
